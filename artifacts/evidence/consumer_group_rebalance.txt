Para evitar que `restart: unless-stopped` lo levantara automáticamente se ejecutó manualmente:

```text
docker update --restart=no agrostream-consumer-2
docker stop agrostream-consumer-2
```

Estado del grupo:

```text
ASSIGNMENT-STRATEGY  STATE    #MEMBERS
cooperative-sticky   Stable   2
```


## Recuperación

Se restauró la política y se levantó el contenedor:

```text
docker update --restart=unless-stopped agrostream-consumer-2
docker start agrostream-consumer-2
```

Resultado real: los tres consumidores quedaron `healthy`, el grupo volvió a `Stable` con `#MEMBERS=3`, y la distribución volvió a ser 2 particiones por consumidor:

```text

consumer-a8b2cea1  (0,1)
consumer-c5016744  (4,5)
```

Lag final: `0` en las seis particiones.
